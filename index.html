Hexo網誌框架 | 套用客製化主題 (Themes)

學習大綱 (Lab Overview)

學習單編號：hexo-002
學習目標：學會如何在 Hexo 官網挑選主題、正確下載主題套件，並修改全域設定檔以套用新主題

  • 需要工具：已經建立好的 Hexo 環境、Git、瀏覽器
  • 核心步驟：
    1. 挑選並評估 Hexo 主題
    2. 下載主題檔案至 themes/ 目錄
    3. 修改全域設定檔
    4. 清除快取並開啟伺服器預覽

實作步驟 (Lab Steps)

Step 1：挑選並評估 Hexo 主題

  1. 開啟 Hexo官網的主題頁面(Themes)
  2. 瀏覽各個主題，點擊感興趣的主題進入其 GitHub 專案裡面
  3. 評估指標
    • GitHub Stars 數：代表熱門度與社群認可度
    • 最後更新時間：若超過一年未更新，未來可能會有套件不相容的問題
    • README 文件完整度：確認是否有詳細的安裝說明與客製化設定範例

Step 2：安裝主題檔

根據該主題 README 的指引進行安裝，常見安裝方式有兩種：

  • 方法 1：使用Git Clone （最常見）
    在 Hexo 根目錄下執行指定
  • 方法 2：使用 npm/yarn 安裝（部分主題支援）

安裝完成後，打開專案下的 theme/ 資料夾，會看到多出一個對應主題名稱的資料夾（例如 themes/example）

Step 3：修改全域設定檔

  1. 開啟 Hexo 根目錄下的 _config.yml
  2. 找到 #Extensions 區塊（約在第 100 行左右）
  3. 將 theme 欄位的值修改為剛下載的主題資料夾名稱

Step 4：清除快取並開啟伺服器預覽

切換主題後，必須清除舊主題產生的快取

開啟 http://localhost:4000/ ，即可看到全新主題效果。

知識小卡（Key Takeaways）

切換主題標準SOP：安裝主題 → 修改根目錄 _config.yml 的 theme 欄位 → hexo clean → hexo server

設定檔的不同：
全域設定檔 (/_config.yml)：負責網站整體資訊、網址、部署與指定套用哪個主題
主題設定檔 (/themes/主題名稱/_config.yml)：負責該主題專屬的樣式、選單列、社群連結與側邊欄設定

學習單（Lab Sheet）

  1. 哪些是選擇主題時需要注意的指標？
    (1) 上次更新時間
    (2) 作者發表的專案數量
    (3) 星星數
  2. 修改根目錄的 _config.yml 套用新主題後，如果畫面沒有改變，可以先執行什麼指定，再開啟server？
    (1) hexo new
    (2) hexo clean
    (3) 霹靂卡霹靂拉拉
    (4) 解除封印
查看解答 1. 上次更新時間、星星數 2. hexo clean

Hexo網誌框架 | 建立個人靜態部落格與 GitHub Pages 部署

學習大綱 (Lab Overview)

學習單編號：hexo-001
學習目標：理解靜態部落格原理，使用 Hexo 建立網站環境，並部署至 GitHub Pages 與設定自訂網域

  • 需要工具：Node.js (建議 LTS 版本)、npm、Git、GitHub 帳號、瀏覽器
  • 核心步驟：
    1. 安裝環境與 Hexo CLI
    2. 初始化部落格環境 (hexo init)
    3. 修改全域設定檔客製化網站
    4. 編譯並部署至 GitHub Pages
    5. 延伸操作：新增文章、頁面與設定個人網域

實作步驟 (Lab Steps)

Step 1：安裝 Node.js、Git 與 Hexo

  1. 到 Node.js官網 下載安裝 LTS 版本。安裝好後開啟終端機輸入 node -v 與 npm -v 檢查版本。

  2. 到 Git官網 下載安裝，開啟終端機輸入 git -v 檢查版本。

  3. 全域安裝 Hexo：npm install -g hexo-cli，完成後可輸入 hexo -v 驗證。
    -g 表示安裝在全電腦環境，非特定資料夾。

Step 2：建立並開啟 Hexo 部落格環境`

  1. 到目標資料夾位置開啟終端機，執行初始化指令：hexo init 網站名稱（英文）
  2. 使用 hexo server 開啟預覽，前往 http://localhost:4000/ 確認畫面正常。
  3. 在終端機按 Ctrl + C 關閉伺服器。
  4. 認識目錄結構：
  • node_modules/: 套件存放區
  • scaffolds/: 文章預設模板
  • source/: 文章與靜態檔案 (_posts/)
  • themes/: 主題樣式
  • _config.yml: 全域設定檔

  1. 編譯為靜態網頁：hexo generate（會跑出 public 資料夾）。
  2. 到 GitHub 開放一個全新的 Repository，並複製專案網址。
  3. 安裝部署套件：npm install hexo-deployer-git --save

延伸學習與踩坑紀錄

  • 新增文章：hexo new '文章標題'（檔案出現在 source/_posts/）

  • 修改內容沒出來：使用 hexo clean 清除暫存檔後再重跑 hexo server

  • 新增獨立頁面：hexo new page 頁面名稱（英文）（出現在 source/頁面名稱/），並需至主題設定檔（如 themes/landscape/_config.yml）修改 menu 新增超連結：

  • 設定個人網域：

  1. 修改 _config.yml 第 16 行的 url 成你的個人網址。

  2. 在 source/ 資料夾新增檔名為 CNAME 的檔案（不要有副檔名），裡面直接寫入網域名稱（不加 https:// 或 www，最後建議換行）。

知識小卡（Key Takeaways）

部落格部署標準SOP：修改文章或設定 → hexo clean → hexo generate → hexo deploy

踩坑筆記與注意事項：
部署語法格式：修改 deploy: 時，建議整段清空再貼上官方字串，以免縮排或原格式殘留造成部署報錯。
自訂網域設定：自訂網域只需要修改 _config.yml 上方的 url，最下方的 # Deployment 網址維持 GitHub 網址。
