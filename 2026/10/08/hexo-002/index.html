Hexo網誌框架 | 套用客製化主題 (Themes)

學習大綱 (Lab Overview)

學習單編號：hexo-002
學習目標：學會如何在 Hexo 官網挑選主題、正確下載主題套件，並修改全域設定檔以套用新主題

  • 需要工具：已經建立好的 Hexo 環境、Git、瀏覽器
  • 核心步驟：
    1. 挑選並評估 Hexo 主題
    2. 下載主題檔案至 themes/ 目錄
    3. 修改全域設定檔
    4. 清除快取並開啟伺服器預覽

實作步驟 (Lab Steps)

Step 1：挑選並評估 Hexo 主題

  1. 開啟 Hexo官網的主題頁面(Themes)
  2. 瀏覽各個主題，點擊感興趣的主題進入其 GitHub 專案裡面
  3. 評估指標
    • GitHub Stars 數：代表熱門度與社群認可度
    • 最後更新時間：若超過一年未更新，未來可能會有套件不相容的問題
    • README 文件完整度：確認是否有詳細的安裝說明與客製化設定範例

Step 2：安裝主題檔

根據該主題 README 的指引進行安裝，常見安裝方式有兩種：

  • 方法 1：使用Git Clone （最常見）
    在 Hexo 根目錄下執行指定
  • 方法 2：使用 npm/yarn 安裝（部分主題支援）

安裝完成後，打開專案下的 theme/ 資料夾，會看到多出一個對應主題名稱的資料夾（例如 themes/example）

Step 3：修改全域設定檔

  1. 開啟 Hexo 根目錄下的 _config.yml
  2. 找到 #Extensions 區塊（約在第 100 行左右）
  3. 將 theme 欄位的值修改為剛下載的主題資料夾名稱

Step 4：清除快取並開啟伺服器預覽

切換主題後，必須清除舊主題產生的快取

開啟 http://localhost:4000/ ，即可看到全新主題效果。

知識小卡（Key Takeaways）

切換主題標準SOP：安裝主題 → 修改根目錄 _config.yml 的 theme 欄位 → hexo clean → hexo server

設定檔的不同：
全域設定檔 (/_config.yml)：負責網站整體資訊、網址、部署與指定套用哪個主題
主題設定檔 (/themes/主題名稱/_config.yml)：負責該主題專屬的樣式、選單列、社群連結與側邊欄設定

學習單（Lab Sheet）

  1. 哪些是選擇主題時需要注意的指標？
    (1) 上次更新時間
    (2) 作者發表的專案數量
    (3) 星星數
  2. 修改根目錄的 _config.yml 套用新主題後，如果畫面沒有改變，可以先執行什麼指定，再開啟server？
    (1) hexo new
    (2) hexo clean
    (3) 霹靂卡霹靂拉拉
    (4) 解除封印
查看解答 1. 上次更新時間、星星數 2. `hexo clean`
