學習單 1. hexo是靜態？動態？擬態?

學習單編號：hexo-001

  1. 目的：建立個人靜態部落格

  2. 需要：node.js, npm, git

  3. 步驟：
    (1) 安裝node, git
    (2) 使用npm安裝hexo
    (3) 建立部落格環境：hexo init 網站名稱（英文）
    (4) 開啟部落格：hexo server
    (5) 修改 config.yml 客製化網站描述
    (6) 編譯 hexo generate
    (7) 部署到github pages

  4. 延伸學習
    (1) 新增文章：hexo new '文章標題'
    (2) 修改內容沒有正確跑出來：hexo clean清除暫存檔
    (3) 新增獨立頁面：hexo new page 頁面名稱（英文）

實作

  1. 到 node官網 安裝，建議選擇LTS(穩定版本)。安裝好之後，可以開啟終端機輸入node -v，如果有跑出版本號，代表安裝成功；安裝node.js的時候，npm也會一併安裝，輸入npm -v，檢查npm版本。
  2. 到 git官網 安裝，安裝好之後，可以開啟終端機輸入git -v，如果有跑出版本號，代表安裝成功。
  3. 使用指令 npm install -g hexo-cli，安裝hexo。安裝好之後，可以使用指令 hexo -v，如果有跑出版本號，代表安裝成功。
    -g ：表示裝在整個電腦上，不是特定的資料夾
  4. 在要建立網站的位置，建立hexo網站，確認終端機目前的位置是要建立資料夾的位置後，hexo init 網站名稱（英文）

打開資料夾後，會出現hexo預設的部落格環境

  1. 使用hexo server打開部落格，如果有出現這樣的畫面就表示環境有建立成功，確認成功後，輸入ctrl+c關閉server

  1. 認識目錄結構
    node_modules: 安裝的套件
    scaffolds: 部落格的暫存格式
    source: 文章存放區
    themes: 樣式
    _config.yml: 全域設定檔
    .gitignore: 忽略清單
    package.json: hexo指令、版本、套件等資訊

  2. 調整全域設定檔 _config.yml

可以修改 #Site 裡面的部落格描述，符合個人需求

項目 內容
title 網站標題
subtitle 網站副標題
description 網站描述
keywords 關鍵字
author 作者
language 語言，預設為英文
timezone 時區，預設使用電腦的時區

修改範例

可參考 Hexo官方-配置

  1. 編譯出網頁看得懂的格式：hexo generate

會出現一個public資料夾

  1. 部署到github pages
    (1) 首先到github開一個新的repository，並把https開頭的網址記下來
    (2) 安裝hexo-deployer-git，npm install hexo-deployer-git --save
    (3) 修改 _config.yml 第15行的url，將改成自己的github帳號，<project> 是你的repository名稱

(4) 修改**_config.yml**的deploy部分，替換成以下內容，並將 <username> 改為自己的github帳號，<project> 是你的repository名稱；branch是指要部署到的分支，可以視需求更改
deploy: type: git repo: https://github.com/<username>/<project> # example, https://github.com/hexojs/hexojs.github.io branch: gh-pages 

**雖然 `deploy:` 看起來都一樣，但我有試過保留原本的deploy:，只把下面的地方換掉，但是會出錯，所以還是建議整段清空再貼上官方的字串會比較好**

(5)執行hexo clean
(6)執行hexo deploy
(7) 到github>repository名稱>settings>pages，開啟網址確認

參考資料：Hexo官方-一鍵部署
