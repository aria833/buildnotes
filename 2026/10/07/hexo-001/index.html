Hexo網誌框架 | 建立個人靜態部落格與 GitHub Pages 部署

學習大綱 (Lab Overview)

學習單編號：hexo-001
學習目標：理解靜態部落格原理，使用 Hexo 建立網站環境，並部署至 GitHub Pages 與設定自訂網域

  • 需要工具：Node.js (建議 LTS 版本)、npm、Git、GitHub 帳號、瀏覽器
  • 核心步驟：
    1. 安裝環境與 Hexo CLI
    2. 初始化部落格環境 (hexo init)
    3. 修改全域設定檔客製化網站
    4. 編譯並部署至 GitHub Pages
    5. 延伸操作：新增文章、頁面與設定個人網域

實作步驟 (Lab Steps)

Step 1：安裝 Node.js、Git 與 Hexo

  1. 到 Node.js官網 下載安裝 LTS 版本。安裝好後開啟終端機輸入 node -v 與 npm -v 檢查版本。

  2. 到 Git官網 下載安裝，開啟終端機輸入 git -v 檢查版本。

  3. 全域安裝 Hexo：npm install -g hexo-cli，完成後可輸入 hexo -v 驗證。
    -g 表示安裝在全電腦環境，非特定資料夾。

Step 2：建立並開啟 Hexo 部落格環境`

  1. 到目標資料夾位置開啟終端機，執行初始化指令：hexo init 網站名稱（英文）
  2. 使用 hexo server 開啟預覽，前往 http://localhost:4000/ 確認畫面正常。
  3. 在終端機按 Ctrl + C 關閉伺服器。
  4. 認識目錄結構：
  • node_modules/: 套件存放區
  • scaffolds/: 文章預設模板
  • source/: 文章與靜態檔案 (_posts/)
  • themes/: 主題樣式
  • _config.yml: 全域設定檔

  2. 到 GitHub 開放一個全新的 Repository，並複製專案網址。

延伸學習與踩坑紀錄

  • 新增文章：hexo new '文章標題'（檔案出現在 source/_posts/）

  • 修改內容沒出來：使用 hexo clean 清除暫存檔後再重跑 hexo server

  • 新增獨立頁面：hexo new page 頁面名稱（英文）（出現在 source/頁面名稱/），並需至主題設定檔（如 themes/landscape/_config.yml）修改 menu 新增超連結：

  • 設定個人網域：

  1. 修改 _config.yml 第 16 行的 url 成你的個人網址。

  2. 在 source/ 資料夾新增檔名為 CNAME 的檔案（不要有副檔名），裡面直接寫入網域名稱（不加 https:// 或 www，最後建議換行）。

知識小卡（Key Takeaways）

部落格部署標準SOP：修改文章或設定 → hexo clean → hexo generate → hexo deploy

踩坑筆記與注意事項：
部署語法格式：修改 deploy: 時，建議整段清空再貼上官方字串，以免縮排或原格式殘留造成部署報錯。
自訂網域設定：自訂網域只需要修改 _config.yml 上方的 url，最下方的 # Deployment 網址維持 GitHub 網址。
